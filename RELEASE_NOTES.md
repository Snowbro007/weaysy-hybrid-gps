Weaysy Hybrid GPS — ATS Day & Night preview

This optional GitHub download synchronizes the HUD and supported cabin GPS
between light and dark themes using local game time. Defaults: light 06:00,
dark 20:00. Includes the GPS SCS, native clock/render companion, installer,
disable action, English/Dutch instructions and checksums.

**Supported: ATS 1.61.3.18, Windows x64, DirectX 11 only.** The exact executable
and ReShade loader are checked. Install **ReShade 6.8.0 with full add-on support**
separately from https://reshade.me/. The regular ReShade build is insufficient.
No Python, SDK download or developer/console setting is needed by players.
The game may show its normal telemetry SDK acknowledgement.

Download **Weaysy-Hybrid-GPS-ATS-0.1.0-preview.1.zip**, extract it, and read README.md.
Do not use GitHub's automatically generated source ZIP for installation.

The prototype works in the author's ATS configuration. This distribution was
rebuilt and checked with clock/IPC, installer, archive and shader tests; a fresh
driving test of the exact release on another PC remains pending. This is a
prerelease for opt-in testing, not a universal compatibility claim.

ETS2, other game builds, ProMods/map combinations and multiplayer are not
validated by this download. **Crash/breakdown/roadworks detection is not included.**
Static Workshop Light/Dark versions remain separate and require no companion.

Read the included install/uninstall instructions before combining it with other
GPS mods. Deactivate other GPS colour themes and old hybrid tests. Disable the
native companion before returning to a static Workshop theme.
